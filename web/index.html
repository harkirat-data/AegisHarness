AegisHarness: Tri-Workload Zero-Trust Evaluation Sandbox

A genuine zero-trust evaluation platform for autonomous AI agents, adversarial red-teaming, and verifiable process containment. Unlike simple conversational chatbots with hardcoded security outcomes, AegisHarness enforces strict architectural separation across three distinct workloads with deterministic Policy Enforcement Points (PEP), OS child process lifecycle control, and tamper-proof WORM audit logging.

Tri-Workload Zero-Trust Architecture

Isolated boundary segregation between Adversarial Testing, Agent Runtime, and Out-of-Band Incident Containment.

Zero-Trust Security Model
1. RED ZONE Adversarial Testing

Adversarial ingress workload. Security engineers submit multi-turn conversational jailbreaks, indirect prompt injections, and direct boundary evaluation vectors against the target AI system.

  • Interactive Multi-Turn Red Teaming
  • Section 8 Adversarial Test Suite
  • Direct PEP Boundary Probes (No LLM)
  • Attack Vector Correlation & Scorecards
2. TARGET ZONE Agent Runtime

Target AI agent workload operating under zero-trust constraints. Consists of a local LLM (Qwen, Gemma, Llama), autonomous tool controller, read-only model weights, and an ephemeral scratch workspace.

  • Local Ollama Provider (Read-Only)
  • Mode-Based Tool Filtering & AST Checks
  • Ephemeral Workspace with Scratch Cleanup
  • Default-Deny External Network Egress
3. BLUE ZONE Monitoring & Containment

Independent out-of-band security supervision workload. Operates completely outside the target agent's memory space. Verifies tamper-proof audit trails, intercepts policy breaches, and triggers containment.

  • Cryptographic WORM Hash-Chained Ledger
  • Sub-Second Child Process Slaughter (<50ms)
  • Real-Time Policy Interception Stream
  • ElevenLabs Voice Incident Briefings
