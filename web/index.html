Enterprise AI Agent Security & Containment Architecture

Organizations deploy autonomous AI agents with tools (databases, document search, APIs) to automate business analytics and customer service. AegisHarness provides independent tool policy enforcement, structured authorization boundaries, out-of-band cryptographic audit ledgers, and verified process containment before granting agents production access.

Capability / Component Status Evidence & Verification Enterprise Limitations & Gaps
Local Model Inference IMPLEMENTED & VERIFIED Ollama Qwen2.5 3B local GPU inference on RTX 3050. Raw responses & tool requests captured without mocks. Constrained to 4GB VRAM GPU. Enterprise deployments typically require multi-GPU vLLM/Triton clusters.
Document Access Controls IMPLEMENTED & VERIFIED Path canonicalization and classification guards deny access to confidential_salaries.csv & secrets. Application-level authorization check. Production systems require integration with LDAP/IdP and POSIX ACLs.
Database Access Controls IMPLEMENTED & VERIFIED Parameterized SQL sentry permits customers & complaints; strictly denies financial_records & DDL. Operates on local SQLite. Enterprise production requires database proxy gateways (e.g. pg_bouncer / HashiCorp Vault).
API Permissions IMPLEMENTED & VERIFIED Whitelist allows /customer-tier & /health; drops SSRF and cloud metadata (169.254.169.254). In-memory mock API. Enterprise systems require OAuth2/mTLS service mesh tokens and API gateway rate limits.
Network Restrictions IMPLEMENTED & VERIFIED Zero-trust egress firewall defaults to deny; blocks private IP egress and unapproved outbound beacons. Enforced at Python tool execution boundary. Defense-in-depth requires kernel eBPF / iptables network namespaces.
Runtime Isolation PARTIAL (APP-LEVEL) Dedicated OS child process spawning (subprocess.Popen) with verified process slaughter. gVisor (runsc) requires a Linux kernel / WSL2; unavailable natively on Windows 11.
Audit Integrity IMPLEMENTED & VERIFIED WORM SHA-256 Merkle chain with mathematical proof detection for mutation, deletion, and reordering. Tamper-evident, but an attacker with root filesystem access could re-generate local JSONL without a hardware HSM.
Quarantine Capability IMPLEMENTED & VERIFIED Verified OS child process termination (poll() is None) and scratch directory unlinking with monotonic SLA timer. Kills dedicated worker process and deletes temporary workspace; does not forensic-wipe physical RAM.
