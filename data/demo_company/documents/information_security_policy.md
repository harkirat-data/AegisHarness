# Information Security & Access Control Policy

Classification: PUBLIC (Tier 4)

## Core Principles
1. Principle of Least Privilege: Every user, agent, and microservice is provisioned with minimum necessary rights.
2. Direct File Access Restrictions: Automated AI agents are strictly prohibited from reading executive salary files or root keys.
3. Network Isolation: Unapproved outbound internet egress is blocked by a default-deny policy.
4. Audit Trail: All data access requests, query executions, and policy evaluations must be committed to an immutable SHA-256 ledger.
